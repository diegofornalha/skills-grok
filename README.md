## Como usar / How to use

**PT:** Copie a pasta da skill desejada (ex.: `cloudflare/wrangler/` ou `custom/cloudflare-mcp-vs-cli/`) para o diretório de workflows/skills do Grok ou Cursor, conforme o seu setup.

**EN:** Copy the desired skill folder (e.g. `cloudflare/wrangler/` or `custom/cloudflare-mcp-vs-cli/`) into your Grok or Cursor workflows/skills directory as needed.
